**Efficiency design.** For each record, set ER edge probability to its full observed edge density (0.032 to 0.135), not to each induced draw. Draw eight independently seeded banks of 56 graphs with 50 nodes each. Compare each bank with the same 32 observed induced graphs by Wasserstein-1; average the eight distances within record. Unreachable pairs contribute zero. Existing Global results average four model-specific W1s with equal instruction weights within model. Frozen WS results average its original eight bank distances; its parameters were selected only on development data. ECDFs illustrate shape, not the cohort-wise W1 ranking. The diagnostic cannot be called blind transfer because it uses the target density.

Equal-record means: Global 0.119224, fixed WS 0.365267, fixed ER 0.373753, target ER 0.153019. Gap closed = (0.365267 - 0.153019)/(0.365267 - 0.119224) = 86.3%, neither causal attribution nor variance explained. Target ER is closer on 5/11 and no more than 0.015 behind on one further record. This tolerance is descriptive. Ten records are overlapping Facebook circles; the school is one record. [Source summaries](../outputs/publication_figures/20261111_v4/efficiency_summary.csv) preserve that distinction. The reference cannot show density is sufficient for the observed structure.

**RQ2 design.** 896 original attempts, 890 valid graphs, 12 empty with undefined mixing, 878 scored. Average available seeds within each of 112 model/method/instruction combinations. Compare marginal categorical Coleman scores with same-attribute edge fraction minus the fraction among all possible distinct roster pairs. Category sizes: politics 17/17/16, religion five groups of ten, gender 20/20/10. Across attributes these scores do not have a proven common importance scale. Politics ranks first on 90/112 Coleman combinations and 85/112 excess-share combinations. All five switches are in Global; neither score ties at the top. Religion/politics Cramer's V = 0.316 for this one designed roster; no population p-value. Prompt order did not vary. Counterbalance order and vary rosters independently to address these explanations in a future experiment.
