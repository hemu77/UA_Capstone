Each control matches the retained source graph in node and edge count.
Uniform controls sample G(n,m); feature controls rank all candidate pairs by equal-weight
four categorical matches and age similarity normalized by the roster age range.
Tie breaks use sorted IDs. Degree controls target 10 swaps per edge and report failure
to reach that target. Rewiring completion is not proof of convergence. One baseline seed
per retained graph is exploratory, not a confidence interval or realism benchmark.
These controls cost no API tokens and do not establish closeness to real networks.
