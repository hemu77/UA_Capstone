Evidence limitations and metric definitions

One US-structured roster, including nine minors with political labels. Historical conditions have two intended seeds; pilot conditions have one. Old language prompts also changed participants' spoken language. Pilot prompt variants and draft translations are not confirmatory replicates. Missing combinations mean no saved result, not a zero effect.

Density: observed edges divided by all 1,225 possible undirected ties. Clustering: mean local clustering, including isolates as zero. Largest component: fraction of all 50 people in the largest connected group. Modularity: seeded Louvain partition score, not proof of real social communities.

Categorical homophily uses the population-weighted Coleman index, (same-group incident-tie share minus population share) / (1 minus population share). Age uses numeric assortativity instead. Undefined values remain unavailable, not zero. These scores are not a causal ranking of demographic importance.

All research metrics come from the shared Python analysis, not a second JavaScript implementation. Missing request logs prevent verification of historical retry rates, model snapshots and costs. Runs with self-links are quarantined, not repaired invisibly. Exclusions may be nonrandom. Browser filters never send API requests.

Audit LLM simulations. Do not use synthetic demographic connections to make decisions about real people. No API requests or keys in this viewer.
